Kubernetes-Friendly Dockerfile

What customers' DevOps teams check in your image. Sources: Pod termination · Logging · Pod Security Standards · Docker build secrets.

Template (Python web app)

FROM python:3.12-slim                                # pinned base tag: reproducible builds
ENV PYTHONUNBUFFERED=1                               # print()/logging reach stdout immediately
WORKDIR /app                                         # working dir for the rest + the app
COPY requirements.txt .                              # deps list first, so the install layer caches
RUN pip install --no-cache-dir -r requirements.txt   # install deps; skip pip's cache = smaller image
COPY . .                                             # code, filtered by .dockerignore
RUN useradd --create-home --uid 10001 appuser        # non-root user with a fixed UID
USER 10001                                           # NUMERIC, so runAsNonRoot can verify it
EXPOSE 8000                                          # documentation: the app's port
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]  # exec form: app is PID 1, gets SIGTERM
.git  .venv  .env  __pycache__  *.pyc                # .dockerignore: keep history, venv, secrets, bytecode out

Customer question → Dockerfile line

They askLineRule
Where are the logs?ENV PYTHONUNBUFFERED=1, CMDstdout/stderr only, never a file. kubectl logs reads those streams.
Graceful shutdown?CMD [...]Exec form. Kubelet sends SIGTERM to PID 1, then SIGKILL after terminationGracePeriodSeconds (default 30s).
Runs as root?USER 10001Non-root and numeric. Without USER, you inherit the base image's user (root for official Python).
Secrets in the image?ENV, ARG, COPYNone. ENV/ARG "persist in the final image". Read secrets from env vars injected by a K8s Secret.
Reproducible?FROMPinned tag or digest, never :latest.
