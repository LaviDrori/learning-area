The four boxes

BoxRuns inHoldsLasts?
① Control planeDatabricks' accountUI, notebooks, SQL editor, Lakeflow Jobs scheduler, Unity Catalogyes
② Serverless computeDatabricks' accountserverless warehouses, notebooks, jobs, pipelinesno, starts/stops
③ Classic computecustomer's cloud accountclusters (all-purpose, jobs), pro/classic warehousesno, starts/stops
④ Object storagecustomer's cloud account*Delta tables (Parquet + log), volumesyes

* A serverless workspace may use Databricks-managed default storage instead. Source: High-level architecture.

What bills

DBUs per second while compute runs        # not bytes scanned (unlike BigQuery on-demand)
classic:    DBUs + VM/disk/network         # VM part on the customer's cloud bill
serverless: DBUs (VM cost included)        # one bill
idle warehouse = still billing             # until auto stop: 10 min serverless, 45 pro/classic

First SQL to run in a new workspace

SELECT current_metastore(), current_user();   -- cloud:region:id of the metastore; who UC thinks you are
SHOW CATALOGS;                                 -- hive_metastore = legacy; system = billing/audit tables
DESCRIBE TABLE EXTENDED cat.schema.tbl;        -- Type MANAGED/EXTERNAL, Provider delta, Location
DESCRIBE HISTORY cat.schema.tbl LIMIT 5;       -- last 5 versions: who wrote what, and how
