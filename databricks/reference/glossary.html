Glossary

The course's single source of truth for terms. Lessons use these words exactly as defined here. Definitions are quoted or adapted from the Databricks docs (AWS pages unless noted).

Platform

TermMeaningFrom
Account"The top-level construct" for an organization: identity, billing, workspaces, metastores.docs · L1
Workspace"The collaboration environment where users run compute workloads". Often one per environment (dev, prod).docs · L1
Control planeBackend services Databricks runs in its own account: UI, notebooks, SQL editor, job scheduler, Unity Catalog.docs · L1
Compute plane"Where your data is processed". Classic: in the customer's cloud account. Serverless: in Databricks' account.docs · L1
Lakehouse"Combines the benefits of data lakes and data warehouses": warehouse-style tables over files in object storage.docs · L1

Unity Catalog

TermMeaningFrom
Unity Catalog (UC)Names, permissions, lineage and audit for data and AI assets, shared by all workspaces attached to its metastore.docs · L1
MetastoreUC's top container, one per region, "registers metadata about data, AI, and permissions".docs · L1
Catalog · schemaThe first two parts of catalog.schema.object. Like a BigQuery project and dataset, but holding only names and grants.docs · L1
Managed tableUC handles governance and the files. The default. DROP deletes the files after a 7-day recovery window (UNDROP until then).docs · L1
External tableUC handles governance only. Files live at a path you manage and survive DROP.docs · L1
VolumeA UC object governing non-table files. Path: /Volumes/<catalog>/<schema>/<volume>/…docs · L1
hive_metastoreThe legacy, per-workspace catalog from before UC. No UC grants, lineage or audit. Migrate away from it.docs · L1
Service principalA non-human identity, such as an app or a job, that can be granted permissions. The Databricks counterpart of a service account.docs · L1

Compute and cost

TermMeaningFrom
DBUDatabricks Unit: "units of processing capability per hour based on VM instance type", billed per second while compute runs.docs · L1
Classic vs serverless costClassic: DBUs + VM, disk and network on the customer's cloud bill. Serverless: VM cost is included in the DBU price.docs · L1
SQL warehouseCompute for SQL (editor, dashboards, BI tools). Types: serverless (recommended), pro, classic.docs · L1
Auto stopStops an idle warehouse after N minutes. Default 10 (serverless) or 45 (pro/classic). Idle warehouses bill until stopped.docs · L1
All-purpose computeA classic cluster for interactive, shared notebook work.docs · L1
Jobs computeA classic cluster created for one job run and terminated when it ends.docs · L1
Photon"The Databricks-native vectorized query engine". On by default for SQL warehouses and serverless.docs · L1

Tables

TermMeaningFrom
Delta LakeThe default table format: Parquet data files + a JSON transaction log, giving ACID transactions.docs · L1
Time travelRead an earlier version with VERSION AS OF / TIMESTAMP AS OF. 7 days back by default. History is kept 30 days.docs · L1
Liquid clusteringData layout that "replaces table partitioning and ZORDER". Recommended for all new tables.docs · L1
Medallion (bronze/silver/gold)A convention, not a feature: raw → validated and cleaned → business-ready tables.docs · L1
