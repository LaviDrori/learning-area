The loop

messages = [user_question]                        # the API is stateless: you keep the history
while True:
    r = model(system, tools, messages)            # one Messages API call
    messages.append(assistant: r.content)         # keep tool_use blocks in history
    if r.stop_reason != "tool_use":               # end_turn / max_tokens / refusal / stop_sequence
        return text_of(r)                         # check refusal & max_tokens in production
    results = [run(call) for call in r.tool_use]  # YOUR code runs tools, never the model
    messages.append(user: results)                # all results in ONE user message, matched by tool_use_id

Source: How tool use works. Runnable version: exercises/0001_agent_loop.py.
