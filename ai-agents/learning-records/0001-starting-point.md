# Starting point: a practitioner with four shipped deployments

Lavi has already built and shipped two agents, each in two deployments: an HR agent (Gemini via the Vertex AI SDK, formerly Google ADK; BigQuery with fixed DDLs + Confluence) on Vertex AI + Cloud Run, and as one Docker container on a customer's Linux machine; and a Tableau extension agent (Anthropic API; field and datasource metadata, org prompt, VizQL queries) on Render, and on a customer's Kubernetes. In both on-prem deployments the agent still calls the cloud LLM API. The open questions span every layer: hosting, framework choice, skills, the turn/conversation data model, prompts and metadata, RAG vs in-context, open-source models, and Bedrock/Vertex.

**Implications:** Skip LLM basics. Lesson 1 builds the five-box map (model, model access, harness, context & tools, hosting) so each later question has a home, and surfaces the likely blind spot: on-prem *hosting* still sends prompts, metadata and query rows to the cloud model, so "on-prem" isn't "nothing leaves". Watch in Lesson 1's answers whether this was already understood. Open facts to collect: whether the HR backend ran on Agent Engine (now Agent Runtime), and whether the Tableau agent uses a hand-written loop.
