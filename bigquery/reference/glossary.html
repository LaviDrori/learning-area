Paying for queries

TermMeaningFrom
On-demand pricingPay per TiB of data a query processes. The first 1 TiB per month per billing account is free.pricing · L1
Capacity pricing / editionsPay for slots per hour (Standard, Enterprise, Enterprise Plus), reserved or autoscaled. Bytes stop being the bill.pricing · L1
SlotA unit of BigQuery compute. Capacity customers buy slots; on-demand queries use shared ones.pricing · L1
Bytes processed / bytes billedProcessed: logical bytes read from the referenced columns. Billed: processed, rounded up to the MB, minimum 10 MB per referenced table.pricing · L1
Logical bytesUncompressed size. On-demand query cost always uses logical bytes.docs · L1
Billing projectThe project a job runs in. It pays for the query, whoever owns the data.docs · L1
JobOne unit of work BigQuery runs for you: query, load, extract or copy. History is in INFORMATION_SCHEMA.JOBS (180 days).docs · L1
Query cacheStored results of a previous identical query on unchanged tables. Cached answers are free (cache_hit in the job history).pricing · L1
Dry runValidate a query and estimate its bytes without reading data. Free. An upper bound. Returns 0 on row-level-secured tables.docs · L1
Query validatorThe console's live dry run: "This query will process … when run".docs · L1
Maximum bytes billedPer-query cap. If the estimate exceeds it, the query fails without a charge.docs · L1

Table design

TermMeaningFrom
Columnar storage"Stores each column separately", so a query reads only the columns it names.docs · L1
PartitionA slice of a table's rows, by a DATE/TIMESTAMP/DATETIME column, ingestion time, or integer range.docs · L1
Partition pruningSkipping partitions the WHERE clause rules out before reading. Needs a constant filter on the partitioning column.docs · L1
require_partition_filterTable option: queries without a pruning filter on the partitioning column fail.docs · L1
ClusteringRows sorted into blocks by up to four columns. Order matters: the first column takes precedence.docs · L1
Block pruningSkipping blocks of a clustered table that the filter rules out. Happens at run time, so dry runs can't show it.docs · L1
